# ADC Figueiras V3 — Auth Pilot

Esta build é uma cópia de desenvolvimento da V2.10 com autenticação Supabase real.

**Importante:** a autenticação, perfil, roles e teste de `app_settings` vêm do Supabase. Os dados operacionais ainda usam armazenamento local V3 separado (`adc-figueiras-team-manager-v3-dev`).

Não substituir a V2.10 estável por esta build enquanto a migração não estiver concluída.
